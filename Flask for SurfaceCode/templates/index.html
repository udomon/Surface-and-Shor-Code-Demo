Surface Code Error Correction

uses Surface_Code.py, click qubits to add errors
Stage 1 of 3: Lattice
An empty surface code lattice
Step 1

Set the lattice

Circles are data qubits. Green squares are stabiliser ancillas: darker green measures X, lighter green measures Z.

Step 2

Inject errors

Click any data qubit to cycle through error types:
1st click: X error, 2nd: Z error, 3rd: Y error, 4th: clear.

No errors yet. Click a data qubit to add one.
Step 3

Correct & verify

Press Correct errors to run the minimum-weight matching decoder from Surface_Code.py. The corrections are applied one pair at a time.
